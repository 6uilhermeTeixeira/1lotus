# Promoção de estratégia

1. O 5lotus produz experimento reproduzível e identifica a versão do dataset.
2. Uma mudança revisada porta o componente aprovado para o 4lotus.
3. O 4lotus executa testes causais e gera um bundle com manifesto e SHA-256.
4. O artifact privado é instalado no 2lotus inicialmente em shadow.
5. Execução exige aprovação separada e todas as travas locais do runner e EA.

Resultado positivo de backtest não autoriza execução.
